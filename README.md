## 📌 Project: SwagLabs Hybrid Automation Framework

### 🔹 Overview

Designed and developed a scalable automation framework for end-to-end testing of the SwagLabs application using Selenium WebDriver, TestNG, and Java. The framework focuses on maintainability, reusability, and cross-environment execution.

### 🔹 Key Highlights

* Implemented **Page Object Model (POM)** to separate test logic and page actions
* Built **data-driven framework** using Excel (Apache POI)
* Integrated **Selenium Grid with Docker** for cross-browser and parallel execution
* Developed **custom TestNG listeners** for automatic screenshot capture
* Configured **Extent Reports** for detailed HTML reporting
* Added **Log4j2 logging** for debugging and traceability
* Enabled execution via **Maven and batch file (run.bat)**
* Designed flexible execution using **config.properties**

---

### 🔹 Technical Implementation

* Centralized WebDriver initialization using BaseTest class
* Parameterized browser execution (Chrome, Firefox, Edge)
* Managed test data externally through Excel files
* Implemented reusable utility classes (ExcelUtil, ScreenshotUtil)
* Structured test suites using TestNG XML files (smoke, regression, sanity)
* Supported both **local execution and Docker-based Grid execution**
